# Portfólio Profissional - Desenvolvedor Full Stack
### Abraão Cezar Inácio

Portfólio frontend 100% dedicado a vagas de **Desenvolvedor Full Stack** (React, TypeScript, Node.js, Python, PostgreSQL, MySQL e APIs RESTful), desenvolvido com **React**, **Tailwind CSS**, **Lucide Icons** e **Vite**.

---

## 🎯 Destaques do Portfólio

- **TCM-GO (Novo Portal do Cidadão):** Construção da interface e componentes reativos da aba *Meio Ambiente* para transparência pública e consulta dos 246 municípios de Goiás.
- **Hero Interativo (Simulador de Código & API):**
  - Editor interativo com abas (`ReactCard.tsx`, `apiRouter.ts`, `schema.sql`);
  - Botão de simulação de chamada de API REST retornando payload real e status HTTP 200 OK em 34ms.
- **Sistemas Completos em Produção:**
  - **Detector de Rachaduras:** Aplicação desktop em Python com PyQt5 conectada ao modelo YOLOv8 para inferência em tempo real;
  - **Projeto Médicos:** Plataforma full stack para gestão de clínicas, agendamento de consultas e prontuário eletrônico;
  - **Emotion Dashboard:** Dashboard reativo com CSS moderno e alta performance visual;
  - **Chatbot Meio Ambiente:** Assistente conversacional em Python.
- **Estudos de Caso Aprofundados:** Modais interativos com Problema, Solução Técnica, Arquitetura e Resultados em produção.

---

## 🚀 Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Rodar servidor local de desenvolvimento
npm run dev

# Gerar build otimizado para produção
npm run build
```

---

## 🌐 Deploy na Vercel

1. Crie um repositório no seu GitHub (ex: `portfolio-fullstack`).
2. Vincule e envie o código:
   ```bash
   git remote add origin https://github.com/cezarbtw/portfolio-fullstack.git
   git branch -M main
   git push -u origin main
   ```
3. Importe o repositório na [Vercel](https://vercel.com) — o deploy ocorrerá automaticamente.
